# Product: Necromancer Council (Kiro Crew app)

Companion to the `necromancer` repo. Four persistent agents operate on
Necromancer through its MCP server (`necro-mcp`):
Gravedigger (triage) -> Coroner (root cause) -> Necromancer (patch) -> Exorcist (proof).
A nightly cron replays every open grave against the latest build.

- Everything in English.
- An agent never claims a fix without a successful replay of the original tape.
- Kiroween 2026: Best Kiro Crew App bonus. Judged on usefulness and technical innovation.
