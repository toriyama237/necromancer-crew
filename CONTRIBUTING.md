# Contributing

Same conventions as the main repository:
[toriyama237/necromancer › CONTRIBUTING.md](https://github.com/toriyama237/necromancer/blob/main/CONTRIBUTING.md).

- `main` (stable) and `develop` (integration) are protected; work in `feature/*`, `fix/*`, `docs/*`, `chore/*` branches.
- Conventional Commits: `type(scope): subject`. Main scopes here: `agents`, `skills`, `sops`, `manifest`, `ci`, `docs`.
- `make setup` installs the git hooks, `make check` runs what CI runs.
